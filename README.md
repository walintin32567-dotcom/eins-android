# Eins 4.0 — Android

Цей репозиторій призначений для складання Android APK зі ZIP-архіву вихідного коду.

1. Завантаж у корінь репозиторію файл `Eins_4_0_GitHub_ROOT_FIXED.zip` через **Add file → Upload files**.
2. Збережи зміни через **Commit changes**.
3. Перейди до **Actions → Build Eins Android APK**, відкрий останній запуск, дочекайся успіху та завантаж артефакт `Eins-4.0-APK`.
4. Розпакуй завантажений артефакт і встанови `app-debug.apk` на Android.

Збірка створює debug APK для особистого тестування, не підписаний реліз для Google Play. Вихідний проєкт містить офлайн-режим і віджети. Не перейменовуй ZIP в APK.
